# Klarineo — Landing Page

Marketing site for **Klarineo**, the app that helps people in Germany understand official letters
(Jobcenter, Finanzamt, Ausländerbehörde, Krankenkasse and more): scan a letter → get a plain-language
explanation in your own language, the extracted deadline (Frist), an AI-drafted reply, a scam-shield
warning, and German speaking practice. Available in English, Russian, Ukrainian, Turkish, Arabic and Uzbek.

Static site hosted on GitHub Pages at **https://klarineo.com**.

## Structure

- `index.html` — landing page
- `privacy-policy.html` — privacy policy
- `assets/logo.svg` — Klarineo logo (also used as favicon)
- `assets/og-image.png` — social share image
- `assets/screenshots/` — app screenshots: `today.png`, `letter.png`, `practice.png`, `paywall.png`
  (framed at ~1206×2622; currently branded placeholders — drop in the final PNGs with zero layout change)
